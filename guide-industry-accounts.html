業種別・よくある経費と勘定科目の考え方

同じような買い物でも、業種によって合う科目は変わります。
業種ごとのよくある経費と、科目の考え方の目安です。

業種で科目が変わる理由

たとえば「ホームセンターで木材を買った」場合、建設業の方なら工事に使う材料（仕入高）ですが、ほかの業種の方なら備品や消耗品かもしれません。勘定科目は、何を買ったかだけでなく、事業の中で何に使うかで決まります。下の一覧は、業種ごとによくある経費と科目の目安です。

業種別の早見表

飲食店

  • 料理の材料（肉・魚・野菜・調味料）→ 仕入高
  • 割り箸・洗剤・ラップ → 消耗品費
  • ガス・電気・水道 → 水道光熱費
  • グルメサイトの掲載料 → 広告宣伝費

小売・ネットショップ

  • 販売する商品 → 仕入高
  • 梱包材・発送の送料 → 荷造運賃
  • 販売手数料・決済手数料 → 支払手数料
  • 広告 → 広告宣伝費

建設・工事・職人

  • 工事に使う資材・部材・塗料 → 仕入高
  • 10万円未満の工具・作業着 → 消耗品費
  • 仕事の車のガソリン → 車両費
  • 資材置き場の賃料 → 地代家賃

美容・理容・サロン

  • 施術に使うカラー剤・パーマ液・ネイル材料 → 仕入高
  • タオル・清掃用品 → 消耗品費
  • 店舗の賃料 → 地代家賃
  • 掲載サイトの料金 → 広告宣伝費

IT・Web・デザイン・ライター

  • クラウド・ソフトの月額 → 通信費または支払手数料
  • 仕事の本・資料 → 新聞図書費
  • コワーキングの利用料 → 地代家賃
  • 10万円未満の周辺機器 → 消耗品費

運送・配達・ドライバー

  • ガソリン・オイル・洗車・車検 → 車両費
  • 高速代・駐車場 → 旅費交通費
  • 梱包材 → 荷造運賃

士業・コンサル・講師

  • 専門書・法令集 → 新聞図書費
  • セミナー参加費 → 研修費
  • 打ち合わせの飲食 → 会議費
  • 貸会議室 → 会議費または地代家賃

医療・介護

  • 手袋・マスク・消毒液など → 消耗品費
  • 提供・販売する医薬品や介護用品 → 仕入高
  • 施設の賃料 → 地代家賃
  • 電気・水道 → 水道光熱費

農業

  • 種・苗 → 種苗費
  • 肥料 → 肥料費
  • 農薬 → 農薬衛生費
  • 家畜のえさ → 飼料費
  • 10万円未満の農具 → 消耗品費
  • 出荷の段ボール・送料 → 荷造運賃

教室・スクール

  • 生徒に配る教材 → 仕入高
  • 教室の文房具・備品 → 消耗品費
  • 教室の賃料 → 地代家賃
  • 生徒募集のチラシ → 広告宣伝費

迷いやすいポイント

  • 10万円以上の物：工具・パソコンなどは、金額によって消耗品費ではなく資産（減価償却）になることがあります。
  • 私用との共用：自宅兼事務所の家賃・電気代などは、事業で使う割合だけを経費にします（家事按分）。
  • 食べ物：同じ食べ物でも、材料なら仕入高、会議なら会議費、取引先との飲食なら交際費、社内なら福利厚生費と、使い道で変わります。
  • 会計ソフトの科目名：会計ソフトや事業所によって、科目の名前が少し違うことがあります（例：地代家賃と賃借料）。

撮るだけ経理での使い方

撮るだけ経理では、はじめに業種（11業種）を選んでおくと、上のような業種ごとの考え方をAIの判断材料にします。業種と関係のない私用の買い物は、業種に寄せずに内容どおりに判断します。

業種を変えるときは、LINEで業種と送ってください。読み取った科目は、記帳の前に「科目を変更」でいつでも直せます。

よくある質問

飲食店が買った食材は、どの勘定科目ですか？

料理の材料として使う肉・魚・野菜・調味料などは「仕入高」にするのが一般的です。社内の差し入れなら福利厚生費、取引先への贈答なら交際費、私用なら経費にしません。

ネットショップの梱包材や送料は、どの勘定科目ですか？

段ボール・緩衝材などの梱包材や、商品を発送した送料は「荷造運賃」にするのが一般的です。

運送業のガソリン代は、どの勘定科目ですか？

仕事で使う車のガソリン・軽油・オイル交換・洗車・車検などは「車両費」、高速道路の料金・駐車場代は「旅費交通費」にするのが一般的です。

農業の種や肥料は、どの勘定科目ですか？

青色申告決算書（農業所得用）では、種・苗は「種苗費」、肥料は「肥料費」、農薬は「農薬衛生費」、家畜のえさは「飼料費」などの科目があります。
