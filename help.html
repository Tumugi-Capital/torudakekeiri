🌱はじめに

撮るだけ経理とは›

撮るだけ経理は、LINEに領収書・レシートの写真やPDF請求書を送るだけで、AIが日付・金額・支払先・取引先・勘定科目・税区分を読み取り、仕訳候補を作成する会計入力アシスタントです。

内容を確認・修正したあと、Money Forward・freeeへの記帳や、弥生会計向けCSV出力まで進められます。新しいアプリのインストールは不要で、操作はすべてLINEの中で完結します。

本サービスは会計入力を補助するサービスです。税務申告、税務代理、税務相談、会計監査、法的助言は提供していません。税務判断が必要な場合は、税理士等の専門家にご相談ください。

登録と初期設定（友だち追加〜プラン申込）›
  1. LINE友だち追加から「撮るだけ経理」を友だちに追加します。
  2. LINEではじめてまたはスタートと送ると、初回の使い方が表示されます。
  3. 料金プラン（ENTRY / PREMIUM）はサービス紹介ページからお申し込みください。お支払いはクレジットカード（Stripe決済）に対応しています。
  4. お申し込み後は、LINEの案内に沿ってご利用ください。

現在はβ版として少人数にテスト提供中です。提供内容・利用条件は改善のため変更する場合があります。

まずは1枚送ってみる（基本の流れ）›
  1. LINEに領収書・レシートの写真を送ります（PDF請求書はファイルのまま送信できます）。
  2. AIが日付・金額・支払先・勘定科目・税区分を読み取り、確認画面を返信します。
  3. 内容が違う場合は「科目を変更」「税区分を変更」から修正します。
  4. 支払方法（現金・事業用クレカ・個人カードなど）を選択します。
  5. 最終確認して、Money Forward・freeeへの記帳、または後日の弥生CSV出力へ進みます。

操作に迷ったら、いつでもLINEでヘルプと送ると、使い方とコマンド一覧を確認できます。

📷レシート・請求書の処理

レシート・領収書を送って仕訳する›

スマホで撮影した領収書・レシート画像をLINEに送ると、AIが解析して仕訳候補を返信します。電子領収書のスクリーンショットにも対応しています。

きれいに読み取るコツ:

  • 明るい場所で、領収書全体が入るように撮影する
  • 文字がはっきり読める距離から撮る（近すぎ・遠すぎに注意）
  • しわを伸ばし、影が入らないようにする

⚠️ クレジットカード決済の「売上票（控え）」と「レシート」は同じ支払いです。二重計上を防ぐため、どちらか一方だけを送ってください。

PDF請求書を送る›

メール添付やWebからダウンロードした請求書PDFを、印刷せずそのままLINEに送信できます。AIが請求書に記載された日付・金額・取引先などを読み取り、仕訳候補を作成します。

スマホでの送り方の例（メールで届いた場合）:

  1. メールの添付PDFを開き、共有ボタンをタップ
  2. 共有先に「LINE」を選択
  3. 送信先に「撮るだけ経理」を選んで送信

読み取り結果は、記帳・CSV出力の前に必ず確認できます。

用途メモで解析の精度を上げる›

レシートだけでは分かりにくい用途を、解析に反映できます。レシートを送る前に、次のように送ってください。

メモ: A社との打ち合わせ　メモ: 東京出張のホテル代

  • メモ確認 — 保存中のメモを確認
  • メモ削除 — 保存中のメモを削除
取引先名を入力・補足する›

AIで読み取りにくい取引先名や、領収書・請求書だけでは分かりにくい相手先は、LINE上で入力・補足できます。

取引先: 株式会社○○のように送ると、解析・記帳に反映されます。取引先情報は記帳・CSV出力の前に確認できます。

勘定科目・税区分を修正する›

AIの候補が違う場合は、支払方法を選ぶ前に確認画面の「科目を変更」「税区分を変更」ボタンから修正できます。

Money Forward・freeeへ記帳したあとの修正は、各会計ソフト側で行ってください。

支払方法の選び方（貸方科目の扱い）›

実際の支払方法に合わせて選んでください。選択に応じて貸方科目が決まります。

  • 現金 → 現金
  • 事業用クレジットカード → 未払金
  • 個人カード・立替払い → 原則として短期借入金（事業主借等の方針がある場合はそちらを優先）
  • 事業用口座・電子マネー・QR決済 にも対応

会社や税理士の会計方針がある場合は、そちらを優先してください。

外貨レシートの扱い›

外貨レシートの可能性がある場合は、記帳前に日本円換算額の入力をお願いしています。

クレジットカード払いの場合は、カード明細に記載された円貨額をご確認のうえ入力してください。実際に使用する換算額は、ご自身または税理士等にてご確認ください。

証憑（領収書画像）の保存について›

PREMIUM PLANでは、Money Forwardへの記帳時に領収書画像を証憑として添付、freeeではファイルボックスへのアップロードをサポートします。

画像が小さい・不鮮明な場合は「証憑保存に不向きな可能性」を警告します。その場合は明るい場所で再撮影してください。

インボイス番号はLINE画面に表示しません（読み取り誤りによる誤解を避けるため）。番号の確認が必要な場合は、添付された領収書画像や原本をご確認ください。証憑対応はインボイス制度への完全対応を保証するものではありません。

🔗会計ソフト連携

Money Forward クラウド会計と連携する›
  1. LINEで連携と送ります。
  2. 表示されたリンクからMoney Forwardにログインし、連携を許可します。
  3. 以降、解析結果の確認後に「記帳」へ進むと、Money Forwardへ仕訳が登録されます。領収書画像の証憑添付にも対応しています。

記帳できなくなった場合は、連携の有効期限切れの可能性があります。もう一度連携と送って再連携してください。

記帳確認画面でMoney Forwardを優先表示したい場合はMFを使うと送ってください。

freee会計と連携する›
  1. LINEでfreee連携と送ります。
  2. 表示されたリンクからfreeeにログインし、連携を許可します。
  3. 以降、解析結果の確認後にfreeeへ取引を登録できます。ファイルボックスへの領収書アップロードにも対応しています。

直近のfreee登録結果はfreee履歴で確認できます。記帳確認画面でfreeeを優先表示したい場合はfreeeを使うと送ってください。

弥生会計へCSVで取り込む›

弥生会計はAPI連携の設定が不要です。日々のレシート・請求書PDFをLINEで処理しておき、月末にまとめて取り込みます。

  1. LINEでCSV出力と送ると、当月の確定済み仕訳のCSVをダウンロードできます。
  2. 月を指定する場合はCSV出力 2026-06のように送ります。
  3. ダウンロードしたCSVを、弥生会計の「仕訳日記帳インポート」から取り込みます。

CSVは弥生会計向けの25列・ヘッダーなし形式（Shift_JIS・CRLF）で出力します。税額は弥生側の自動計算に任せる設計です。

主に使う会計ソフトを設定・切り替える›
  • 会計ソフト — 現在の会計ソフト設定を確認
  • MFを使う / freeeを使う — 記帳確認画面で優先表示する会計ソフトを切り替え
  • 登録履歴 — Money Forward・freee・承認状況をまとめて確認（二重登録の防止にも役立ちます）

💳料金・お支払い

料金プランの内容（ENTRY / PREMIUM）›
  • ENTRY PLAN — 550円/月（税込）：レシート画像・PDF請求書のAI解析、仕訳候補の作成、用途メモ・取引先入力、科目・税区分の確認。会計ソフト連携・証憑対応は含まれません。
  • PREMIUM PLAN — 1,100円/月（税込）：ENTRYの内容に加えて、Money Forward記帳、freee取引登録、弥生会計CSV出力、領収書画像の証憑対応。

どちらも月額固定で、枚数による従量課金はありません。

現在の契約プランはLINEでプランと送ると確認できます。お申し込みはサービス紹介ページから。

🛠トラブル・お問い合わせ

よくあるエラーと対処法›
  1. Money Forwardに記帳できない
    LINEで連携と送って、Money Forwardを再連携してください。
  2. 連携したのにエラーになる
    権限や有効期限の問題の可能性があります。まず連携と送って再連携してください。
  3. 証憑添付だけ失敗した
    記帳自体は完了している場合があります。必要に応じて、Money Forward側で画像を手動添付してください。
  4. 「画像が小さい」と表示された
    証憑保存に不向きな可能性があります。明るい場所で、文字がはっきり読める距離から再撮影してください。
  5. 勘定科目・税区分が違う
    支払方法を選ぶ前に「科目を変更」「税区分を変更」ボタンから修正できます。
  6. 外貨レシートと判定された
    カード明細などで日本円換算額を確認し、円換算額を入力してください。

解決しない場合は、スクリーンショット・操作内容・エラーIDをLINEに送ってください。LINEでエラーと送ると、この対処法一覧をいつでも確認できます。

エラーIDについて›

処理に失敗した際、メッセージにエラーIDが表示されることがあります。お問い合わせの際にこのIDを添えていただくと、原因の確認がスムーズになります。

エラーIDと、発生した操作の内容・スクリーンショットをそのままLINEに送ってください。

LINEの返信が遅い・返ってこない›

LINE公式アカウントの月間通数上限や、一時的な通信状況により返信が遅れる場合があります。時間をおいて再度お試しください。

β期間中は安定運用に向けて順次改善しています。長時間返信がない場合は、お手数ですが時間を変えてもう一度お送りください。

お問い合わせ・フィードバックを送る›

不具合のご報告・ご質問・ご要望は、LINEでお問い合わせまたはサポートと送ると連絡方法をご案内します。

使ってみた感想はフィードバックと送ってください。読み取り精度、勘定科目の自然さ、記帳の分かりやすさなど、ひとことでも改善の参考になります。
